# 团队选做(推荐)

两道题,2-4 人一组,二选一或都做。允许使用 AI(见仓库根目录的 AI 政策,
团队题不受"不得让 AI 给出完整解答"的限制——这两道题没有标准答案)。

- C1(`c1_flashkda/`):FlashKDA 的官方 kernel 停在 SM80 MMA,值不值得
  上 SM100?
- C2(`c2_msa_decode/`):MiniMax M3 MSA 的小 batch decode 还是 Triton,
  值不值得做专用 kernel?

两题都是三层结构:复现/测量 → 分析(讨论点逐个给"结论 + 证据")→
挑战。挑战层做不出正收益也算完成:把"为什么不值得做"论证扎实,和做出
加速一样是合格结论。

答辩每组 10 分钟 + 5 分钟提问,提问优先来自做另一道题的组。

需要可构建的完整仓库时按 TASK.md 里记录的 pin commit 自行 clone。
